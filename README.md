# 🎙️ OmniVoice Thai

OmniVoice Thai เป็นแอปพลิเคชันบนเว็บ (พัฒนาด้วย Gradio) สำหรับทำ Voice Cloning หรือการโคลนเสียงภาษาไทยแบบออฟไลน์ คุณสามารถใส่ข้อความภาษาไทย เลือกเสียงต้นฉบับ และสร้างเสียงพูดที่เลียนแบบน้ำเสียงต้นฉบับได้อย่างรวดเร็ว

## ✨ ฟีเจอร์หลัก (Features)
- 🇹🇭 **รองรับภาษาไทยเต็มรูปแบบ**: แปลงตัวเลข, วันที่, เบอร์โทรศัพท์ และคำอ่านให้ถูกต้องตามหลักภาษาไทย
- 🎤 **Voice Cloning**: ใช้ไฟล์เสียงสั้น ๆ หรือยาว เพื่อเป็นต้นแบบ (Reference) ในการสร้างเสียงพูดใหม่
- ✂️ **จัดการคลังเสียงและตัดต่อเสียง**: อัปโหลด, จัดการ, และเลือกตัดช่วงเสียง (Trim) ที่ต้องการได้ภายในแอปพลิเคชัน
- 💬 **Non-Verbal Tags**: รองรับการแทรกเสียงเอฟเฟกต์อารมณ์ลงในประโยค เช่น เสียงหัวเราะ `[laughter]`, เสียงถอนหายใจ `[sigh]`, เสียงตกใจ `[surprise-ah]` ฯลฯ
- ⚡ **Local AI Processing**: ประมวลผลแบบ Local 100% รักษาความเป็นส่วนตัวและทำงานได้รวดเร็ว
- 📝 **Auto-Transcription**: มีระบบ Whisper ในตัวสำหรับถอดเสียงคำพูดในคลิปเสียงต้นฉบับ (Ref Text) ให้อัตโนมัติ

## 🚀 วิธีการติดตั้ง (Installation)

1. **โคลนโปรเจ็คนี้ (Clone the repository)**
   ```bash
   git clone https://github.com/xIaMMaIx/Omnivoice_TH.git
   cd Omnivoice_TH
   ```

2. **สร้าง Virtual Environment (แนะนำ)**
   ```bash
   python -m venv venv
   # สำหรับ Windows
   venv\Scripts\activate
   # สำหรับ Mac/Linux
   source venv/bin/activate
   ```

3. **ติดตั้ง Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## 🎯 วิธีการใช้งาน (Usage)
สำหรับ Windows สามารถรันโปรแกรมได้ง่าย ๆ โดยดับเบิ้ลคลิกไฟล์ `run.bat` หรือเปิดผ่าน Terminal ด้วยคำสั่ง:
```bash
python App.py
```
เมื่อเซิร์ฟเวอร์รันสำเร็จ โปรแกรมจะเปิดหน้าต่างเบราว์เซอร์อัตโนมัติ (ปกติจะอยู่ที่ `http://localhost:7860/`)

### ขั้นตอนการสร้างเสียงเบื้องต้น:
1. ไปที่แท็บ **📁 จัดการคลังเสียง** อัปโหลดไฟล์เสียง หรืออัดเสียงใหม่
2. ไปที่แท็บ **🎤 โคลนเสียง** พิมพ์ข้อความภาษาไทยที่ต้องการ
3. เลือกเสียงต้นฉบับ แล้วกด **🚀 เริ่มสร้างเสียง**
